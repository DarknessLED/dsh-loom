## Why the numbers moved

The old bill was `usageOfSession(ctx, sessionId)` called after the child had
been disposed: `sessions.get(childId)` answered nothing, so the round fell
back to `fallbackSpend(brief, text)` — characters ÷ 4. Three separate gaps hid
behind that one estimate:

1. the cost meter is a client-side RPC (`remote.costMeter`), not a service the
   plugin can read with `svc(ctx, 'costMeter')`;
2. the host writes `session.v4.jsonl.zstd`, which the reader did not open;
3. that file is a *sequence* of zstd frames, one per flush — 161 KB of frames
   decompress to 270 bytes when only the first frame is read, so the usage
   blocks live in frames the single-shot decoder never sees.

All three are now pinned by `tests/self15/billing-from-ledger.test.mjs`.

## What is still missing

- `priceSource` is `default` on every round so far: the per-model table is
  implemented (`pricingFor`), but no campaign has been given a split table yet,
  so there is nothing to observe. Configure `models.pricing` for a campaign
  before claiming the per-relay part is exercised.
- `cause: unrecorded` on old campaigns is honest: they stopped before
  `campaign.finished` existed. New stops record their cause.
- Round 17 promoted a no-op (the tree already satisfied the verifier) and the
  selector re-bought a task that had landed by hand. Both were fixed by making
  the manual landing visible to the reducer; the no-op path itself is still
  allowed by design.
